# 🏯 K-Spot Trend (케이 스팟 트렌드)
> **“AI가 당신의 여행 취향을 하나의 로컬 에디토리얼 매거진으로 편집한다.”**

---

## 1. 서비스 명
* **서비스 국/영문 명칭**: K-Spot Trend (한국의 숨은 트렌드를 걷다)
* **슬로건**: “AI가 당신의 여행 취향을 하나의 로컬 에디토리얼 매거진으로 편집한다.”

---

## 2. 서비스 정의
* **정의**: 사용자가 여행하고자 하는 도시와 선호 분위기(K-Pop 성지순례, 감성 카페, 로컬 미식, 인생샷 포토존)를 선택하면, AI가 현지인 검증 명소를 기반으로 **최적화된 1일 맞춤 코스를 추천하고 시각화해 주는 다국어 여행 큐레이션 플랫폼**
* **핵심 지향점**: 단순 텍스트 나열을 넘어 **“언어 장벽 없는 직관적 UI(KR/EN), 1일 서킷 동선 다이어그램, 브라우저 로컬 저장소 기반의 오프라인 코스 보관함”** 제공

---

## 3. 기획 배경 (문제 인식)
* **획일화된 외국인 관광 코스**: 명동, 경복궁 등 전형적인 관광 코스에 편중되어 강릉, 경주, 안동 등 매력적인 지방 도시의 MZ 핫플레이스 접근성 부족
* **언어 및 길찾기 진입 장벽**: 한국 특유의 지도 데이터 규정으로 구글 지도 도보 안내가 제한적이며, 해외 여행객을 위한 실전 꿀팁(네이버/카카오 지도 활용, 교통카드 충전 등) 안내 부족
* 🔥 **핵심 문제**: *“현지인들이 진짜 즐기는 감성 로컬 명소를 외국인과 내국인 모두 쉽고 체계적인 동선으로 안내받을 도구의 부재”*

---

## 4. 서비스 발전 과정 (MVP ➔ Multilingual Travel Curator)
실제 인터페이스 검증과 글로벌 사용자 편의성을 반영하여 2단계 이터레이션을 거쳐 완성되었습니다.

    [Phase 1. 초기 단일 페이지 프로토타입] ───► [Phase 2. 5-Page 다국어 여행 플랫폼]
    · 구조: index.html 중심 단일 코스 생성     · 구조: 5개 멀티 페이지 (AI 추천 / 핫플 / 동선 / 꿀팁 / 보관함)
    · 언어: 한국어 중심 한정 출력               · 언어: UI 및 AI 생성 결과 전면 다국어(KR/EN) 동기화
    · 데이터: AI 1회성 응답 휘발                · 데이터: LocalStorage 연동 1일 코스 오프라인 영구 보관
    · 동선: 텍스트 위주 리스트                 · 동선: 대중교통 환승 정보 포함 1일 서킷 시각화 & 지도 연동

* **초기 프로토타입 단계 (Phase 1)**:
  * **핵심 기능**: 도시/테마 선택 후 Gemini AI를 통한 1일 타임라인 추천 생성
  * **한계점 발견**: 페이지 간 유기적 정보(지역 핫플 모아보기, 교통 팁 등) 제공이 부족하고, 영어 지원 부재로 해외 여행객 활용 불가
* **최종 고도화 단계 (Phase 2 - Full Curation Platform)**:
  * **5-Page 구조 분리**: AI 코스 추천(`index.html`), 로컬 핫플 갤러리(`spots.html`), 동선 지도(`map.html`), 여행 가이드(`guide.html`), 내 보관함(`saved.html`)으로 모듈화
  * **중앙 집중형 i18n 엔진 구축**: `lang.js` 기반 `data-i18n` 딕셔너리 매핑을 통해 전 페이지 100% 실시간 언어 전환(KR/EN) 지원
  * **AI 프롬프트 다국어화**: 백엔드(`prompts.py`)에서 `lang` 파라미터를 수신하여 추천 코스 및 팁을 영문/국문 타깃 언어로 완벽 분기 생성

---

## 5. 해결 전략 (3단 구조화)
* **5.1 프롬프트 엔지니어링 & 핫플 결합**: 도시별 검증 핫플레이스 DB(`spots_data.py`)를 기반으로 환각(Hallucination)을 억제하고 현실적인 1일 시간대별 타임라인 도출
* **5.2 전 페이지 실시간 다국어 동기화**: `localStorage`에 사용자의 언어 설정을 영구 동기화하여 페이지 이동 시에도 일관된 KR/EN 인터페이스 유지
* **5.3 오프라인 코스 보관함**: 네트워크 연결 상태와 무관하게 마음에 드는 일정을 브라우저 저장소(`kspot_saved_routes`)에 담아 현지 여행 중 즉시 확인 가능

---

## 6. 주요 기능 상세 명세
* **6.1 AI 맞춤 코스 큐레이터 (`index.html`)**: 권역별 드롭다운, 도시 빠른 선택 칩, 4대 여행 분위기 필터를 조합해 1일 추천 코스 즉각 생성
* **6.2 로컬 핫플 디렉토리 (`spots.html`)**: BTS 버스정류장, 안목 커피거리, 황리단길 등 지역별 감성 명소 갤러리 및 지역별 필터링 기능
* **6.3 여행 동선 시각화 서킷 (`map.html`)**: 강릉, 경주, 안동의 랜드마크를 잇는 대중교통/도보 스텝 다이어그램 및 네이버/카카오 지도 원클릭 연동
* **6.4 필수 여행 핸드북 (`guide.html`)**: 국내 내비게이션 현실, 카드/교통카드 현금 충전법, 식당 호출벨 문화, KTX 사전 예매 등 실전 팁 수록
* **6.5 내 보관함 (`saved.html`)**: 생성된 맞춤 코스 편철, 날짜별 메타데이터 확인, 코스 개별 삭제 관리 기능
* **6.6 예외 처리 및 운영 모니터링 UX**:
  * **로딩 스피너**: AI 지연 시간 동안 펄스 인디케이터로 처리 진행 상태 명확히 전달
  * **Discord Webhook 연동**: 추천 코스 생성 성공/실패 여부를 실시간으로 운영 채널에 자동 전송

## 7. 타겟 사용자 및 니즈 분석
* **주 타깃**: 한국의 트렌디한 로컬 감성을 체험하고 싶은 글로벌 여행객 및 MZ세대 자유여행자
* **부 타깃**: 복잡한 일정 계획 없이 핵심 인생샷 명소와 동선을 빠르게 추천받고 싶은 국내 당일치기 여행자
* **사용자 니즈**:
  * 구글 맵만으로는 알기 어려운 최신 SNS 핫플과 실제 대중교통 이동 팁 해소
  * 나만의 여행 코스를 별도 가입 없이 즉시 저장하고 열람할 수 있는 가벼운 도구

## 8. 기술 아키텍처 및 디렉터리 구조

### 8.1 시스템 기술 스택
* **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES Module System)
* **Backend**: Vercel Serverless Functions (`api/recommend.py`, `Python 3.9+`)
* **AI Engine**: Google Gemini API (`gemini-2.5-flash`)
* **Deployment & CI/CD**: GitHub, Vercel
* **Security & Ops**: `GEMINI_API_KEY`, `DISCORD_WEBHOOK_URL` 환경 변수 분리

## 9. UX 및 데이터 처리 흐름

    1. [사용자 도시/테마 선택] ───> 2. [언어 상태 감지 (KR/EN)] ───> 3. [fetch('/api/recommend', POST)]
                                                                               │
                                                                               ▼
    6. [보관함 저장 / 오프라인 열람] <── 5. [타임라인 렌더링] <─────── 4. [recommend.py + Gemini AI]
       (localStorage 저장)              (render.js)                           │
                                                                               └─> [Discord Webhook 알림]

* **1~2단계**: 사용자가 도시, 여행 분위기를 고르면 `lang.js`에서 현재 활성화된 언어 코드(`ko`/`en`)를 읽어와 페이로드를 구성합니다.
* **3~4단계**: `/api/recommend` 엔드포인트로 데이터가 전송되며, `prompts.py`의 언어 지침에 맞춰 Gemini 모델이 구조화된 JSON 타임라인을 생성합니다. 동시에 운영 관리자용 Discord Webhook으로 실행 알림이 전달됩니다.
* **5~6단계**: 수신된 JSON 데이터를 파싱하여 시간대별 감성 일정과 사진 촬영 팁을 화면에 렌더링하며, 사용자가 [📌 코스 저장하기]를 클릭하면 `localStorage`에 영구 편철되어 `saved.html`에서 언제든 확인할 수 있습니다.

## 10. 향후 확장 계획 (Roadmap)
* **10.1 지도 경로 실시간 길찾기 API 연동**: 네이버/카카오 지도 웹 딥링크(Deep Link)를 자동 생성하여 클릭 한 번으로 도보/대중교통 길찾기 실행
* **10.2 나만의 코스 PDF 내보내기 (Travel Itinerary Pass)**: 저장된 코스를 영수증/티켓 형태의 감성 모바일 패스 및 A4 출력용 PDF로 다운로드 지원
* **10.3 사용자 로컬 제보 시스템 (Community Spots)**: 현지 주민들이 직접 숨은 스팟을 등록하고 검증받을 수 있는 크라우드소싱 큐레이션 서가 구축
